# 🎮 Connect 4 AI Web Game

A modern browser-based Connect 4 game built using HTML, CSS, and JavaScript. Players can compete against an AI opponent or play with a friend in local multiplayer mode.

---

## 📖 Project Description

Connect 4 AI Web Game is a responsive web application inspired by the classic Connect Four board game. The game includes an intelligent AI opponent, score tracking, winner detection, smooth animations, and confetti celebrations.

This project demonstrates front-end web development concepts, game logic implementation, DOM manipulation, and basic Artificial Intelligence techniques.

## 🎮 How to Play

1. Open the game in a web browser.
2. Choose a game mode:

   * One Player (vs AI)
   * Two Players
3. Click a column to drop your piece.
4. Create groups of four connected pieces.
5. Earn points for every valid four-piece connection.
6. When the board is full, the player with the highest score wins.

---

## 🤖 AI Logic

The AI works by:

* Identifying available columns
* Simulating potential moves
* Checking immediate scoring opportunities
* Prioritizing beneficial moves
* Selecting random valid moves when no better move exists
